# UI/UX Document

### 1. Design Aesthetics
- **Color Palette:** Professional Deep Blue (Trust), Emerald Green (Success).
- **Typography:** Inter font, modern sans-serif.

### 2. Core Screens
- **Dashboard:** Kanban board showing jobs in states: Found, Drafting, Applied.
- **Profile Settings:** Where users upload their base resume and API keys (if needed).
- **Review Modal:** Side-by-side view comparing job description with the AI-generated cover letter.
