# Software Requirements Specification (SRS)

### 1. Technology Stack
- **Database & Auth:** Supabase (PostgreSQL, Row Level Security).
- **Backend API:** Python FastAPI.
- **AI Agent Framework:** LangGraph + Langchain.
- **LLM:** Groq API (Llama 3).
- **Web Scraping/Search:** DuckDuckGo Search API.
- **Frontend:** Next.js with Tailwind CSS.

### 2. Database Tables
- **Profiles:** Stores user information and base resume.
- **Jobs:** Stores discovered job postings.
- **Applications:** Tracks status of each job application.
